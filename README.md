# Electricity Bill Calculator

### ▶ Description
This program calculates the total electricity consumption and total electricity bill

### ▶ Version 1 - Original code w/o input validation
* Input: Asks for customer name, previous meter reading, and current meter reading
* Process: Calculates the total electricity consumption and total electricity bill
* Output: Customers Name, Electricity Consumption, and Total Electricity Bill
* Does not include input validation

### ▶ Version 2 - Updated Working code w/ input validation
* Input: Asks for customer name(loops back if blank), previous meter reading(loops back if less than zero), and current meter reading(loops back if less than previous reading)
* Process: Calculates the total electricity consumption and total electricity bill
* Output: Customers Name, Electricity Consumption, and Total Electricity Bill
* Includes Input Validation
